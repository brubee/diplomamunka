This repository is for my master's thesis project.

# Built game link

The folder necessary to run my game can be found at the following link: [Diplomamunka built game folder](https://drive.google.com/drive/folders/1SMhs7AE4fHaPN4u5hf3QLb0d4CyjZ2aE?usp=sharing).

To play the game, please download the entire folder. The game itself is called "Rejtély.exe" which is what you will need to launch for the game.

Happy gaming!
